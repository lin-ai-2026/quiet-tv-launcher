# 源码核实：可以对外讲的点，以及不能讲的点

这是对照当前公开树源码写的核对记录，方便以后写介绍时不把未验证的东西说成已发生。它不是真机评测，不是性能报告，也不是已经发出的文案。没有耗时、代码行数、帧率、功耗的测量数字。

家里的机器记录是 TCL 55T5M、32 位。源码清单的历史字段是 5.3.1 / code 11，包名 `com.lin.magazinehome`。公开树版本名是 `5.3.1-public.1`。**没有用这份源码对照那份已安装 APK，也没有在这台电视上跑过。**

## 可以讲，因为源码里写了

- 自己做的电视主屏幕，不是在系统桌面上盖一层小组件。入口是 `HOME`。
- 遥控器方向键焦点是自己排的：首页一排入口，设置页左右改选项。没有用 Leanback 那套行列表控件。
- 首页同时放时钟、日期、一行新闻。农历走系统 ICU。节气是一段近似太阳黄经，当天跨过 15° 才显示，不是万年历库。
- 壁纸可以来自必应、纯色、文件夹、图片链接、手机上传。公开树里的「内置精选」和「暗色」是内存里的纯色渐变，因为原来的图片文件没有放进仓库。
- 手机和电视走同一 Wi-Fi 上的一个小页面：扫码、上传照片、回桌面、切 HDMI、打开电视上已经安装的投屏接收应用。HTTP 服务是自己写的，没有再套一个 Web 框架。二维码用的是 Nayuki 的生成库，许可头在源文件里。
- 屏保有四种黑白时钟，也可以登记成系统的 Dream。
- 切 HDMI 的代码是按 TCL 的 LiveTV Activity 写的，并监听 `TvInputManager` 的输入状态。

## 不能讲成已经证实

- 不能说公开源码就是电视里那个 5.3.1 安装包。
- 不能说已经在 TCL 55T5M 上验证无信号黑屏、信号恢复、开机进 HDMI、休眠唤醒、待机闪黑。源码里有这些路径，这次没有上电视。
- 不能给省电百分比、内存占用、启动时间。界面上的「暗色（省电）」只是一个壁纸来源的名字。
- 不能说完全离线或绝不上传。新闻、天气、必应、自定义链接都会出网；自动定位还会查 IP 地理接口。
- 不能说局域网页面绝对安全。配对链接在同一网络里就是控制权。页面本身没有方向键，但服务端仍接受那类指令。
- 不能说附带了已授权的摄影壁纸或思源/Noto 字体。那些文件被排除了，公开树改用系统字体和自绘渐变、图标。
- 不能说调试 APK 可以覆盖家里已装的那一版。签名不同，系统会拒绝。它也不是应用商店发布。
- 不能说电视上跑了人工智能模型。AI 只参与写代码和写说明。

## 介绍时用得上的一句

极简电视桌面是一个 Java 写的 Android TV 启动器：方向键焦点、时钟和一行新闻、手机扫码换壁纸。HDMI 切换按 TCL 的接口写了，但这份公开树还没有在真机上验收。
